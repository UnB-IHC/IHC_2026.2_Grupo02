# Grupo 02 - IHC 2026.2

## Sobre o repositório

Este repositório tem como propósito fornecer um checklist prático de acessibilidade e conceitos de Interação Humano Computador para projetos, principalmente de desenvolvimento de software, que incluem: desenvolvimento web, design, geração de conteúdo e gestão de projetos.
